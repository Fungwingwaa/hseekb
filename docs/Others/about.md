# <i class="bi bi-info-circle-fill" style="color:var(--theme-color)"></i> 关于本站

生态环境领域涉及的法律、行政法规、行业标准等规范文件的数量繁多，知识涵盖面广，政策关联性复杂。为方便查阅资料，本站收录和整理相关内容，旨在搭建一个条理清晰、使用便捷的生态环境知识库。数据主要来源于[国家法律法规数据库](https://flk.npc.gov.cn/)、[国家生态环境部](https://www.mee.gov.cn/)、[广东省生态环境厅](http://gdee.gd.gov.cn/)等权威发布网站，欢迎学习交流。

### <i class="bi bi-grid-1x2-fill"></i> 分类汇总

本知识库将规范性文件分为[<i class="bi bi-file-earmark-text-fill"></i>法规库](Laws/index)和[<i class="bi bi-bookmark-fill"></i>标准库](Standards/index)2个子库，法规库参照法律位阶分成法典、法律、行政法规等9大类，标准库分为GB国家标准、DB地方标准、HJ技术规范3大类。
